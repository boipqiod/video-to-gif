# Simon's Tools

A personal collection of handy browser-based tools with no installs or sign-ups.
Files are processed locally and never leave your device.

## Tools

- Video to GIF — choose a clip, frame rate, size, and color count
- Universal Converter — convert PDF, HEIC/HEIF, JPG, PNG, and WebP into JPG, PNG, WebP, or PDF
- Image Compressor — coming soon
- Image Resizer — coming soon
- PDF Toolkit — coming soon
- QR Code Maker — coming soon

## Run locally

```bash
npm install
npm run dev
```

## Validate

```bash
npm run lint
npm run typecheck
npm run build
```

Every push to `main` is deployed to GitHub Pages through GitHub Actions.
