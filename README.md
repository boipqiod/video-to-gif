# Simon's Tools

설치나 회원가입 없이 브라우저에서 바로 쓰는 개인 웹 툴박스입니다. 파일은
서버로 전송되지 않고 사용자의 기기 안에서 처리됩니다.

## 도구

- Video to GIF — 영상 구간, FPS, 크기와 색상 수를 조절해 GIF로 변환
- 이미지 압축 — 준비 중
- 이미지 크기 조절 — 준비 중
- 이미지 형식 변환 — 준비 중
- 이미지를 PDF로 — 준비 중
- QR 코드 만들기 — 준비 중

## 로컬 실행

```bash
npm install
npm run dev
```

## 검증

```bash
npm run lint
npm run typecheck
npm run build
```

`main` 브랜치에 푸시하면 GitHub Actions가 GitHub Pages에 자동 배포합니다.
